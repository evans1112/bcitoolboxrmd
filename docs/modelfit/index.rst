Model Fitting
=============

Model fitting estimates BCI parameters from behavioral data. The toolbox
supports discrete-response and continuous-response datasets, strategy
comparison, batch fitting, result visualization, and export.

Choose the fitting workflow that matches the response format in your
experiment:

Discrete fitting
   Use when participants choose from predefined response categories, such as
   reporting one of several possible numbers of flashes or beeps.

Continuous fitting
   Use when participants report freely on a continuous scale, such as spatial
   location or temporal position.

Other settings
   Review shared controls such as simulation count, strategy choice, parameter
   bounds, and output options.

For two-dimensional experiments, see :doc:`../basic_usage/gui2d`.
